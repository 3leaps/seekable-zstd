# v0.1.2 Release Notes

## Highlights

- Go encoder support: write `.szst` archives directly from Go (`Encoder`, `NewEncoder`, `Finish`).
- New encoder C FFI (`seekable_encoder_*`) with consistent `seekable_last_error()` reporting.
- Go encoder tests covering roundtrip, random access across frames, empty input, and abort safety.

## Notes

- This release remains Go-centric and does not publish to language registries.
- Encoder compression level tuning is intentionally deferred (tracked for v0.1.3).
